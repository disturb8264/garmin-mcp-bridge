# 실행 파일

이 폴더에는 컨테이너 실행에 필요한 설정·토큰·Garmin 로컬 데이터가 놓입니다. Git에는 이 안내 문서와 하위 폴더의 안내 문서·`.gitignore`만 포함됩니다. 실제 실행 파일은 각 폴더의 `.gitignore`가 제외합니다.

- [Garmin 실행 파일과 생성 방법](garmin/README.md)
- [게이트웨이 실행 파일과 생성 방법](gateway/README.md)

모든 명령은 저장소 루트에서 실행합니다. NAS에 배포할 때는 두 폴더의 실제 파일을 별도로 안전하게 복사하고, 컨테이너 UID가 토큰을 읽을 수 있도록 권한을 맞춥니다.
