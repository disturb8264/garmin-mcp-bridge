# 스키마 확장

`sql/schema.sql`은 초기 테이블을 생성하는 기준 파일입니다. 새로운 데이터 종류나 컬럼은 `002_설명.sql`, `003_설명.sql`처럼 번호를 붙인 SQL 파일로 추가합니다. `ensure_schema()`는 각 파일을 한 번만 트랜잭션으로 적용하고 `garmin_schema_migrations`에 기록합니다.

새 Garmin API 필드는 실제 응답을 확인한 뒤 매핑합니다. 원본 응답은 해당 데이터 테이블의 JSONB에 보존하고, MCP에는 필요한 요약 필드만 노출합니다. VO2max, HRV, 수면 등 일일 지표는 별도 테이블과 수집 모듈로 추가합니다.
